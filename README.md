# carrie-ebook-project
# CARRIE — Електронне видання (Стівен Кінг)

Навчальний проєкт із верстки електронної книги та організації роботи в системі контролю версій GitHub.

## Структура гілок репозиторію:
- `main` — фінальна версія електронної книги та зібрані матеріали проєкту.
- `draft` — робоча гілка для редагування та структурування тексту.
- `design` — гілка для підготовки обкладинки та візуального оформлення.
